# TML Template Files

This directory contains blank template files for the TML Data Loader tool.

## Required Files

Please place the following template files in this directory:

1. **Source_Data_Template.xlsx** - Blank source data template
   - Should contain a "Source_Data" sheet with all required column headers
   - Used as a reference for users to prepare their input data

2. **TM_Loader_Template.xlsx** - Blank TM_Loader template
   - Should contain "Assets" and "TML" sheets with proper structure
   - Used as a reference for the template file format

## Usage

These templates are downloaded by users via the TML Data Loader frontend interface to help them prepare their data files correctly.

## File Format

- Both files should be Excel format (.xlsx)
- Column names must match exactly as specified in the TML Data Loader documentation
